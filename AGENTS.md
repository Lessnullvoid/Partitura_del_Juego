# Autoría del repositorio

La autoría y las contribuciones de este proyecto deben atribuirse únicamente
al propietario, Lessnullvoid (identidad Git existente: Microhom
<microhom@gmail.com>).

- Conservar la identidad Git del propietario al crear commits.
- No añadir agentes, asistentes, bots ni herramientas como autores, coautores
  o colaboradores del repositorio.
- No añadir trailers `Co-authored-by` ni créditos automáticos de herramientas
  en commits o documentación.
- Conservar los cambios de trabajo existentes que no pertenezcan a la tarea.
